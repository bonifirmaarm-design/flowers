# ЦВЕТЫ — бутик авторских букетов

Демонстрационный (портфолио) сайт цветочного магазина. Тёмная «винная» эстетика,
крупная типографика, «жидкое стекло» (liquid glass) в навигации и каталог букетов
с фильтрами. Первая версия — десктоп-first, с адаптацией под планшет и телефон.

## Что внутри

```
index.html            # вся страница (герой, разворот 01/02, каталог, сборка букета, футер)
assets/
  css/styles.css      # дизайн-система (токены, стекло, глубина, motion)
  js/app.js           # каталог, фильтры, избранное, сортировка, параллакс, reveal
```

Открыть локально: просто откройте `index.html` в браузере (интернет нужен для
шрифтов Google Fonts и изображений).

## Дизайн-решения (по референсам)

- **Герой** — крупная засечная «ЦВЕТЫ» (Playfair Display) с наложением живых
  цветов спереди и сзади букв + курсивный подзаголовок «которых достойна каждая».
- **Стеклянная панель** из нижнего блока референса перенесена **наверх** как
  плавающая навигация (Apple-style liquid glass: blur + внутренняя подсветка).
- **Каталог букетов** — сетка карточек с бейджами скидок, ценой и старой ценой,
  избранным, фильтрами (тип, повод, цвет, стоимость-слайдер, гамма) и чипами.
- **Карточки товара** — букет «выходит» за верхнюю границу карточки (эффект из
  референса), при наведении — лёгкий подъём и свечение.
- Живые цветы «прорастают» из вёрстки (magnolia bleed) как в основном референсе.

## Изображения

Все фотографии сгенерированы в **Krea** (модель **Krea 2 Large**, лучшая для
выразительной фотореалистичности) под единым тёмным арт-дирекшеном под референсы.
Файлы `*.webp` лежат в корне репозитория и подключаются локально — сайт полностью
автономен, интернет нужен только для шрифтов Google Fonts.

Запрошенная модель *Wan 2.2* в каталоге Krea для text-to-image недоступна
(Wan — это видео-модель), поэтому взят топовый фото-движок.

## Шрифты

- Дисплейный — **Cormorant** (тонкие начертания 300–500), как на референсах.
- Курсив подзаголовков — **Cormorant Garamond Italic**.
- Интерфейс — **Inter** (300–500).

## Дизайн-скиллы (anti-slop)

Принципы взяты из открытых agent-skills по фронтенд-дизайну (клонированы в
`design-skills/`, в репозиторий не коммитятся из-за размера):
Refactoring UI (шкалы отступов/типографики, иерархия, глубина), taste-skill,
scroll-craft (слои глубины, motion), impeccable (токены/сдержанность),
ui-ux-pro-max, interface-design, designer-skills, hallmark.
